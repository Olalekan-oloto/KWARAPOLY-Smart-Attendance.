Course and class setup

A class is defined by institute, department, study mode, programme, level, session and semester. A lecturer can only take attendance for an assigned class.

The official institute, department, programme and course catalogue must be confirmed by the Polytechnic before production launch. Admins will be able to maintain it without changing code.

Attendance session preview

Production attendance will use a short-lived signed session token, one submission per enrolled student, server-side time checks and an audit trail. A screenshot or copied permanent QR will not count as valid attendance.
